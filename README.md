Entry for the [make.fun bounty](https://make.fun/bounty/u-alven-the-battery-s-last-text-to-its-charger-4278cfab):
the phone battery's last text message to the charger it waited for all day, one line
of plain text.

> Charge the human instead. He's drained.

The program (`main.ts`) writes that one line to `/output/entry.txt`.
